# Módulo 2 do curso Cubos Academy

Neste módulo iremos criar um servidor com nodeJS e aprender sobre controladores, rotas e funções.

Aula 02/04 - Conteúdo

- Como criar rotas
- Como criar rota com parametros que vem do browser
- Como criar rota com parametros de consulta (key params) que vem do browser
- Controladores que são funcões logo após a rota
- Tipos de Middlewares
    - Middlewares independentes = "Não estão atrelados com rotas, é um intermediario que antes da requisição chegar ate a rota passa por ele"
    - Middlewares de rota = "Quando há a necessidade de se fazer verificações que são pertinentes para uma ou mais rotas, mas não em todas"
